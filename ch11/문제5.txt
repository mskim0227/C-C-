문제 5 열거형(enum)의 상숫값 이해 (코드 실행 결과 예측)
다음 열거형(enum)을 활용한 코드의 실행 결과를 쓰시오.

#include <stdio.h>

enum TrafficLight {
    Red,
    Yellow,
    Green
};

int main() {
    enum TrafficLight signal = Green;

    printf("Value: %d\n", signal);

    switch (signal) {
        case Red:
            printf("Stop\n");
            break;
        case Yellow:
            printf("Caution\n");
            break;
        case Green:
            printf("Go\n");
            break;
        default:
            printf("Unknown\n");
    }

    return 0;
}







문제 5 정답:
Value: 2
Go
- 해설: 열거형 멤버 상수는 별도의 값을 지정하지 않으면 첫 번째 멤버부터 0, 1, 2 순으로 자동 할당됩니다. 따라서 Red는 0, Yellow는 1, Green은 2의 값을 가지며, switch문에서 case Green:이 실행되어 Go가 출력됩니다.
